# Apple Weather Clone

A weather application built with React, TypeScript, and Vite. The UI is designed to mimic the iOS Weather app using Tailwind CSS.

## Features

- Current weather, hourly forecast, and 10-day daily forecast
- Interactive weather charts (temperature, wind, precipitation)
- Glassmorphism UI with dynamic backgrounds based on current weather conditions
- Geolocation support and local storage for saved cities
- Russian localization

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Recharts
- Lucide React
- Framer Motion

## Running locally

```bash
# install dependencies
npm install

# start dev server
npm run dev
```

## Project Structure

- `src/api/` - Open-Meteo API integrations
- `src/components/` - React components
- `src/utils/` - Helpers for data formatting and local storage
- `src/types/` - TypeScript interfaces
